# Life, In Receipts

A cinematic archive revealing stories, signals, and connections across personal digital life records.

## Development

You need Node.js and npm/bun to run this project locally.

```sh
npm install
npm run dev
```

To build for production:

```sh
npm run build
```

## Built with

- TanStack Start & TanStack Router
- TypeScript
- React
- Tailwind CSS
